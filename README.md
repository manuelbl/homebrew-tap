# Homebrew Tap

Homebrew casks for apps by manuelbl.

## Install

```bash
brew install --cask manuelbl/tap/camcontrol
```

## Casks

| Cask | Description |
| --- | --- |
| [camcontrol](Casks/camcontrol.rb) | [CamControl](https://github.com/manuelbl/CamControl): menu bar utility to adjust USB webcam settings |
